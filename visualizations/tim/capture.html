The timer stamps the button press. Your code reads the stamp.

TIM5 never stops counting. On every edge of the button line it copies the count into CCR1 by itself. Four small labs below let you step through it, break it, and tune it.

05 · easy to get wrong

Gotchas

Reading CCR1 clears CC1IFRead it first in the ISR, even if you ignore the value.
OvercaptureA second edge before the read overwrites the stamp. CC1OF flags it. Clear by writing 0.
16 µs filter is not debounceBounce lasts ms. The ISR still checks the quiet time.
Read the pin inside the ISRThe edge was µs ago, so IDR still shows which way it went.
Why TIM5lib/pwm.c owns TIM2. TIM5 is the other 32-bit timer.
71.6 min limitOne counter wrap between presses is fine. Two are not.
