A timer makes a pin wave. Four gates sit between them.

The counter runs on its own. Each channel compares it with one number, turns the answer into a level, optionally flips it, and then either connects it to the pin or not. Change one gate and watch where the wave changes.

04 · easy to get wrong

Gotchas

CCR above ARR holds the output highIn PWM 1, CNT is always below CCR, so OCxREF never falls (RM0390 §17.3.9; comment at lib/pwm.c 61). CCR = 0 holds it low.
Flipped polarity flips the dutyWith CCxP = 1 a 25 % setting gives 75 % at the pin. PWM 2 gives the same wave as PWM 1 with a flip.
CCxE = 0 gives a silent pinThe counter and the compare keep running and OCxREF still moves. Only the gate to the pin is shut.
Without preload the duty changes mid-periodWith OCxPE = 0 a CCR write is used at once and the current pulse comes out short or long. With it, the new value waits for the wrap.
PSC, ARR and CCR writes are not live yetWith preload they wait for an update event. That is why the init forces one with UG before starting.
CC1S must be 00CC1S chooses input or output. Output needs 00, and the code clears it before setting OC1M.
