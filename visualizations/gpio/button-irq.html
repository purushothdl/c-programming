A falling edge wakes the core. One press, one toggle.

PC13 sits high behind a pull-up. Pressing it pulls the line low, SYSCFG hands that edge to EXTI line 13, and IRQ 40 runs the handler. The handler clears the flag and toggles the LED, as long as 20 ms have passed since the last accepted press.

04 · easy to get wrong

Gotchas

PR13 clears by writing 1Not 0. Clearing it is what ends the request; skip it and the handler is entered again the moment it returns (tab 3).
The vector is sharedLines 10 to 15 all use IRQ 40. Check PR & PR13 first, or you act on another pin's edge.
The guard starts at the last pressIt is a lockout, not a quiet-time measure. Two real presses 10 ms apart become one toggle (lab, double tap).
Both triggers double the togglesWith RTSR set, the release is an interrupt too. This handler never reads the pin, so it toggles on both edges.
Resolution is 1 msThe guard reads SysTick ticks. Edges inside the same millisecond all see quiet = 0, whatever the sub-millisecond timing.
No SysTick, no pressesWithout the 1 ms tick, g_ms_ticks − g_last_press_ms is always 0, so every edge is rejected. The button looks dead.
