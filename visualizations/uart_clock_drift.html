UART clock mismatch: why the stop bit saves you

An asynchronous UART has no shared clock. The receiver samples each bit using its own clock, so any baud-rate error makes the sample point slide across the bit. Drag the error slider and watch where the sample dots land.

Mid-bit gives the most margin both ways.

Transmitted signal (8N1)

Each frame = 1 start bit (0) + 8 data bits LSB first + 1 stop bit (1). Frames sent back to back.

Sample-point drift over time

How far each sample is from the true bit centre, in bit-widths. Inside the green band the bit is read correctly; beyond it, the sample falls into the neighbouring bit.

Corrupted bytes vs clock error

20 random bytes sent at each error value. Free-running receivers fall over almost immediately; the UART tolerates roughly ±5% in theory (≈ 0.5 bit ÷ 9.5 bits to the middle of the stop bit), and a few percent in real hardware.
