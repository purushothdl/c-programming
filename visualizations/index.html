Step through the code. Change a number, see what breaks.

One page per program or peripheral. Every page follows the shared design and is built from the real source lines and the manuals.

UART uart/

Ring buffer

Type letters and watch the interrupt fill the ring. Switch between a realistic and a busy main. Drag a slider to see why head & 7 finds the slot.

programs/uart_echo_irq.cnew style TX interrupt

Send "hi" and watch TXEIE arm and disarm. Four tabs, two of them bugs. A calculator shows when main has to wait.

lib/uart.cnew style Print and parse

Type your own input and step through print_dec32, print_hex32, parse_u32 and tokenize line by line.

lib/fmt.cnew style Clock error

Which baud rates fit the error budget at 16 MHz. Drag the clock error and see where the samples land in a frame.

lib/uart.c · RM0390 §25.4new style Receiver, tick by tick

16 ticks per bit and a 3-sample vote. Add a flipped bit or a short glitch, or a low pulse on an idle line, and see which flag it sets (NF, FE, PE).

TIM5 input capture

Five event sequences (two of them bugs), a debounce tuning lab, and a register builder for CCMR1 and CCER.

programs/tim_capture/main.cnew style Timer channel path

Follow one channel from counter to pin through its four gates. Cut one, flip one, and see all four pins on one analyser. Build CCMR1 and CCER and work out period and duty.
