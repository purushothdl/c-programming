lib/uart.c · uart_putc, USART2_IRQHandler

main queues the text. The interrupt feeds the wire.

The wire is about a thousand times slower than the CPU. So uart_putc only puts the byte in a ring and flips one switch, TXEIE. The interrupt handler then moves one byte at a time into the USART.

02 · when does main wait?

How long is main blocked?

uart_putc waits only while the TX ring is full. Pick a message or drag the length. The first 64 bytes queue at once, then main is paced by the wire.

03 · easy to get wrong

Gotchas

Push first, then armArmed with an empty ring, the ISR disarms at once and the byte is stuck (tab 2).
Disarm when the ring is emptyTXE stays 1 while idle. Left armed, the interrupt never stops (tab 3).
One byte per interruptThe ISR writes one byte to DR. TXE rises again when DR empties, and that is the next interrupt.
A full ring blocks mainThe while loop in uart_putc spins until the ISR frees a slot (tab 4, and the calculator).
First byte skips the waitOn an idle line a write to DR goes straight to the shift register and TXE is set again at once (RM0390 p. 781).
HardFault cannot use thisThe ISR may not run, so fault_putc polls TXE and uart_drain_polled disarms the interrupt first.
