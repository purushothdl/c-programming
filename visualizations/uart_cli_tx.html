How main sends text with the TX interrupt

Part 1 of uart_cli.c. main puts bytes into a ring. The interrupt handler moves them one at a time into the USART. The switch that makes the USART call the handler is TXEIE. Step through it, forward and back.

Text main sends

Main sends it with uart_puts, which calls uart_putc for every character. The ring here has 4 slots so you can see it fill.

When main arms the interrupt

The real code is lines 92, then 93. The second option swaps them.

When the handler disarms

The code clears TXEIE on line 298. The second option leaves it on.

Try these

  1. Press Next through hi. Watch the three lamps. The IRQ line is on only when TXEIE and TXE are both on.
  2. Find the step where the handler runs with an empty ring. It switches TXEIE off. Then find where main switches it on again.
  3. Choose Never under the disarm rule. See what happens once the ring is empty.
  4. Type h, and choose Before the push. The byte never leaves.
The wire is about a thousand times slower than the CPU. The progress bar and the step counts are not to scale. They only keep the order of events right.
