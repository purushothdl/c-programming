Toy model, not clock cycles. The CPU needs 24 accesses (two, then a thinking slot, repeated). The DMA copies 4 words, which is 8 accesses (read, then write), starting at slot 6. Burst takes 8 slots in a row. Cycle stealing takes every second slot. Transparent only uses slots the CPU does not need.

02 · our chip: many roads

The bus matrix

The STM32F446 has separate paths to Flash, SRAM1, SRAM2 and the peripherals (RM0390 Figure 1, p.54). Pick what each master wants. Two masters only collide when they want the same target. Then the matrix takes turns, round-robin (p.55).

Presets:

Simplified: every master asks for its target in every round and one access is served per target per round. DMA1 is left out (its peripheral port goes straight to the APB bridges in Figure 1) and so is the USB OTG HS DMA (the text and the figure disagree about its route to Flash).

04 · three things to remember for the code

What the manual says

SPI1 is on DMA2 onlySPI1_TX is DMA2 stream 3 or stream 5, channel 3. DMA1 has no SPI1 request (Table 29 p.204 and Table 28).
Set it up while EN is 0The direction bits can only be written while the stream is disabled (p.227). The counter can only be written while disabled too (p.228). A counter of zero serves no request, even with the stream on.
"Complete" is not "sent"When the DMA flag TCIF sets, the SPI is still shifting the last byte. Wait for TXE = 1, then BSY = 0, before you change CS or disable the SPI (p.840). The order for starting: stream first, then TXDMAEN, then SPE.
