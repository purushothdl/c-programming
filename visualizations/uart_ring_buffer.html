How the UART interrupt hands bytes to main

Each received byte triggers the interrupt handler, which drops it into a ring of slots. main collects the bytes later, at its own speed. Two counters, head and tail, keep them from getting in each other's way. This page uses 8 slots so you can see every one. uart_echo_irq.c uses 64 and follows the same rules.

Why there are two counters

The handler and main work on the same ring at different times, and the handler can run in the middle of main. Each side gets one counter that only it changes.

head

  • The next slot to write.
  • Only the interrupt handler changes it.
  • main reads it to see if the ring is empty.

tail

  • The next slot to read.
  • Only main changes it.
  • The handler reads it to see if the ring is full.

If both sides wrote one shared variable, an interrupt landing between main's read and write of it would erase an update. With one writer per counter, that cannot happen, so no lock is needed. A stale read is also safe. If main sees an old head, it thinks the ring has fewer bytes than it really does and picks the rest up on the next pass.

The pair also gives the fill level: head − tail slots hold data. Zero means empty, 8 means full. A single position could not tell the two apart, because both look like "head sits on tail". Counters that keep counting can: after 8 writes, head is 8 ahead of tail, not on top of it.

Why head & 7 finds the slot

The counter keeps counting up, but the ring has only 8 slots. The slot is how far into the current lap the counter is, which is the remainder after dividing by 8. In binary, the lowest 3 bits of the counter are exactly that remainder. The bits above them count the laps. AND with 7 (0b111) keeps the 3 low bits and clears the rest. Drag the slider.

Why the size must be a power of two

Two things break otherwise. First, the mask must be all ones in binary, like 0b111, to keep a whole group of low bits. Second, the counter is 32 bits, so after 4294967295 it wraps to 0. The slot sequence must carry on from where it was. That works only when 2³² is a whole number of laps, which is true for sizes that divide it: 4, 8, 16, 64.
