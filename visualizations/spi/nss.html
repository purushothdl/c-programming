01 · the master's one privilege

Only the master makes the clock

A slave cannot move a single bit by itself. Bits shift only when SCK pulses, and only the master drives SCK. Try to make the slave send something on its own.

Each board has a byte loaded. Nothing moves until the master clocks.

So B can send data to A while A is master: A's clock pulls B's byte across. What B cannot do is choose when. That is why devices that need to speak first use a separate "data ready" wire, or take the bus themselves (section 03).

05 · easy to get wrong

Gotchas

SSI = 0 on a master is a faultThe manual says a master with its internal NSS low gets a mode fault, "NSS pin in hardware mode, or SSI bit in software mode". No wire needed: a wrong SSI alone does it.
PB6 is not NSSThe program's chip select is a plain GPIO. The SPI1 NSS pin is PA4 or PA15 (AF5). They never interact when SSM = 1.
A fault locks the way backAfter MODF, read SR, then write CR1, with NSS high. The hardware will not let SPE or MSTR be set while MODF is still set.
SSOE is for one slave onlyWith SSM = 0 and SSOE = 1 the master drives NSS low whenever SPE = 1. Fine for one slave, no use for several.
Shared MISO needs careSlaves that share one MISO wire must set the pin to alternate-function open-drain, and an unselected slave releases it.
SSM = 1 frees the NSS pinThe pin can then be used for something else, because the chip no longer reads it.
