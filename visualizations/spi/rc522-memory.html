01 · three separate stores

Where does a byte go inside the RC522?

Three memories sit behind one SPI door. The address byte decides which one you touch. Click the buttons and watch which box changes.

64 registers 6 address bits

Addresses 0x00 to 0x3F. Each one is a single byte: a setting, a status, a command.

64-byte FIFO one queue

A waiting line of up to 64 bytes. It is not the 64 registers. The same number is a coincidence.

Registers p.36 · address = cell number

Grey cells are the ones this page models. Cell 09 is special: it is the door to the FIFO queue.

FIFO queue p.29 · 0 of 64 bytes

Written at the back (dashed cell), read from the front (first cell). Only reachable through register 09.

Internal buffer p.71 · 25 bytes

No address. Only the Mem command moves bytes in or out, through the FIFO. ?? = unknown: reset does not clear it.

Pick a register and press Send.

Reset values shown: CommandReg 0x20 (p.38), ComIEnReg 0x80 (p.38), RxSelReg 0x84 (p.52, also what your board read), AutoTestReg 0x40 (p.66), FIFOLevelReg 0x00 (p.44). VersionReg shows your chip's 0x92.

03 · one SPI frame

How does the chip tell an address from data?

By position. After CS goes low the first byte is always an address. What the later bytes mean depends on read or write (datasheet p.10, p.11).

04 · the three confusions

Short version

Two different 64s64 registers have 64 addresses. The FIFO holds 64 bytes. Different things.
0x80 is an action, not a numberWriting 0x80 to FIFOLevelReg sets bit 7 (FlushBuffer): "empty the queue". Nothing stores 128.
One address, many bytesA register has one byte. The FIFO door (09) takes many bytes in order, so one address byte starts a whole burst.
Sources: MFRC522 datasheet Rev. 3.9 (Components/MFRC522.pdf): register map p.36, CommandReg p.38, FIFO p.29 and p.44, command set p.70-71, SoftReset p.73, SPI framing p.10-11, self test p.82, AutoTestReg and VersionReg p.66, RxSelReg p.52. Code lines: lib/rc522.c. Simplified: the model only has the registers listed; FIFO overflow, empty reads and every command except Idle, Mem and SoftReset are not modelled. Assumptions, not stated in the datasheet: Mem takes the first 25 bytes in order and removes them from the FIFO; a soft reset empties the FIFO because FIFOLevelReg's reset value is 0. Nothing on this page was measured on the chip.
