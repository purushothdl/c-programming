# MPU-6500 — 6-axis motion sensor — Key Sections

Document: `~/Books/Hardware-and-Systems/Components/MPU6500.pdf`
(InvenSense, "MPU-6500 Product Specification", Rev 1.1, 41 pages; PDF page N = the printed "N of 40")

Gyroscope + accelerometer + temperature sensor, with an SPI and an I2C port. It is an
off-board part: its registers are not in the SVD.

Full-scale selects: GYRO_CONFIG bits 4:3 = 250 / 500 / 1000 / 2000 dps (p.14). The
accelerometer full-scale field is in ACCEL_CONFIG (p.14-15). The sensitivities (LSB per g and per
dps) are in the product specification, 3.1-3.2 (p.9-10).

## SPI facts used by the code (all from p.34 and p.16)

- The chip is always an SPI slave. CS low at the start, high at the end of a transfer.
- First byte = `R/W` (1 = read, 0 = write) then 7 address bits. Data follows in 1 or more bytes.
- Data latched on the rising edge of SCLK, changed on the falling edge. The datasheet does
  not name the mode number; that is the standard description of mode 0 (CPOL 0, CPHA 0).
- **fSCLK max 1 MHz** (Table 7). On the STM32 at 90 MHz (SPI1 on APB2) that means BR 6
  (703 kHz) or BR 7 (351 kHz); BR 5 is 1.4 MHz and too fast.
- Register access is valid within 100 ms of power-up (11 ms typical, p.12): the program waits 100 ms.
- The module may have NCS pulled up for I2C; the SPI-only bit (USER_CTRL I2C_IF_DIS, register map p.40) is set by `reset`.

The module-to-chip mapping is inferred from the pin names printed on the board and the
