# SN74HC595 — 8-bit shift register with output latch — Key Sections

Document: `~/Books/Hardware-and-Systems/Components/sn74hc595.pdf`
(Texas Instruments SN54HC595 / SN74HC595, SCLS041J, 41 pages)

A write-only chip: bits shift in on SER at each rising edge of SRCLK, and a rising
edge on RCLK copies them to the eight outputs. It has no registers and no ID.

Facts the code relies on: the first bit shifted in ends up in QH after 8 clocks, so with SPI
MSB-first bit 7 appears at QH and bit 0 at QA (follows from the function table). QH' is the
serial output of the 8th stage, so a second byte clocked in reads the first byte back out.
