# PM0214 — STM32 Cortex-M4 Programming Manual — Chapter Index

Document: `~/books/Hardware-and-Systems/STM32/pm0214-stm32-cortexm4-mcus-and-mpus-programming-manual-stmicroelectronics.pdf`
(262 pages, 228 TOC entries, Rev 10)

Covers the **ARM Cortex-M4 core** (programmer's model, exceptions, instruction set, core
peripherals). It does **not** cover ST peripherals (GPIO, USART, ...) — those are in RM0390.
Core peripherals (NVIC, SCB, SysTick, MPU, FPU) are the Private Peripheral Bus registers at
`0xE000_E000`+; look them up here rather than in RM0390.

Page numbers are **PDF page numbers** (they match the printed numbers in this document).
